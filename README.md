# Kotlin Task Manager

A simple command-line task manager developed in **Kotlin** as part of the Rocketseat Kotlin learning journey.

## Features

* Add new tasks
* List all tasks
* Search tasks by ID
* Update task completion status
* Delete tasks by ID
* Filter completed tasks
* Filter pending tasks
* Automatically generate unique task IDs
* Validate task data
* Display formatted task information
* Count total tasks
* Automatically register task creation date and time

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/FelipeLuizonDev/task-manager-kotlin
```

2. Navigate to the project folder:

```bash
cd task-manager-kotlin
```

3. Open the project in IntelliJ IDEA or another Kotlin-compatible IDE.

4. Run the `main` function from the `Main.kt` file.
